**website structure**

the site is built with github pages and jekyll.

main pages:

- home
- writing
- about
- contact

writings are stored as markdown files in the `writing` folder.

each writing uses the standard article template.

the article template provides the metadata and content structure.

jekyll uses the article layout to create the published article page.

each article has a permalink.

github keeps the history of changes to each article.

the website may later include search or other ways of finding writings.

**current setup**

- github pages
- jekyll
- markdown articles
- `_config.yml`
- `_layouts/writing.html`
- `_templates/writing.md`
- `writing/`
